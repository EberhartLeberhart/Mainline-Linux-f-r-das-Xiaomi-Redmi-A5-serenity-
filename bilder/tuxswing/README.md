# TuxSwing – Start-Maskottchen

![TuxSwing](tuxswing.png)

TuxSwing ist eine KI-unterstützt gestaltete, jazzige Interpretation von Tux, dem Linux-Maskottchen.
Das Artwork wurde 2026 mit ChatGPT gestaltet.

## Hinweis zu Tux

gezeigte Pinguinfigur ist eine Nachbildung von Tux und keine eingebundene Originaldatei.

Tux wurde von Larry Ewing mit The GIMP erstellt. Für das zugrunde liegende Tux-Design gelten die jeweiligen Rechte und

## Projektbezug

TuxSwing ist ein unabhängiges Community-Artwork für das Mainline-Linux-Projekt auf dem Xiaomi Redmi A5. Es ist kein
offizielles Logo des Linux-Kernel-Projekts und stellt keine offizielle Unterstützung durch das Linux-Projekt dar.

## Verwendung im Projekt

Geplant als Startbild (Plymouth); dank der GPL-2.0-Option später auch als Kernel-Logo möglich. Die Kreideziege an der
Wand ist eine Hommage an das Projekt-Maskottchen. Tanz und Musik erst, wenn Kernel und Ton stabil sind.
